# Hackstreet-Boys
Hospital management simulator
We hace used the help of google gemini and microsoft copilot.
The program consists of HTML and Python
The Ai models used the following sources:-
1. Emergency Department Triage & Clinical ProtocolsGilboy, N., Tanabe, P., Travers, D., & Rosenau, A. M. (2011). Emergency Severity Index (ESI): A Triage Tool for Emergency Department Care, Version 4. Implementation Handbook (AHRQ Publication No. 12-0014). Rockville, MD: Agency for Healthcare Research and Quality.Relevance: Provides the clinical rationale for 3-tier and 5-tier triage classification systems, prioritizing patient acuity and acuity-based resource allocation.Iserson, K. V., & Moskop, J. C. (2007). Triage in medicine, part I: Concept and history. Annals of Emergency Medicine, 49(3), 275–281.Relevance: Explores ethical and operational principles behind hospital triage prioritization algorithms during capacity constraints.
2. Queueing Theory & Healthcare Operations ResearchGreen, L. V. (2006). Queueing analysis in healthcare. In R. W. Hall (Ed.), Patient Flow: Reducing Delay in Healthcare Delivery (pp. 281–307). Boston, MA: Springer.Relevance: Examines multi-server priority queueing models ($M/M/c$ queues) applied to hospital bed management, patient delays, and bed utilization rates.Hall, R. W. (Ed.). (2012). Patient Flow: Reducing Delay in Healthcare Delivery (2nd ed., Vol. 206). Springer Science & Business Media.Relevance: Provides theoretical frameworks for bottleneck identification, room turnover strategies, and emergency surge capacity planning.
3. Discrete-Event Simulation (DES) in Health ServicesJacobson, S. H., Hall, S. N., & Swisher, J. R. (2006). Discrete-event simulation of health care systems. In Patient Flow: Reducing Delay in Healthcare Delivery (pp. 211–252). Springer, Boston, MA.Relevance: Establishes methodology for probabilistic patient arrival distributions, stochastic stay durations, and speed-multiplier simulation loops.Jun, J. B., Jacobson, S. H., & Swisher, J. R. (1999). Application of discrete-event simulation in health care clinics: A survey. Journal of the Operational Research Society, 50(2), 109–123.Relevance: Benchmarks system modeling for clinic resource tracking, bed allocation, and staff scheduling.
4. Software Architecture & Web EngineeringGrinberg, M. (2018). Flask Web Development: Developing Web Applications with Python (2nd ed.). Sebastopol, CA: O'Reilly Media.Relevance: Technical foundation for lightweight REST API construction, JSON routing, and CORS-enabled microservices in Python.Hipp, R. D. (2020). SQLite Database Engine Architecture and SQL Specification. SQLite Development Team.Relevance: Reference for relational database persistence, schema definitions, and ACID transactions for local state storage.Tailwind Labs Inc. (2023). Tailwind CSS: A Utility-First CSS Framework for Rapid UI Development. Available at: https://tailwindcss.comRelevance: UI component design system and dynamic dark-mode dashboard styling.
